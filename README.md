# DAWWERHA – دَوَّرها

تطبيق أندرويد (Jetpack Compose + Room) لإعادة التدوير وإعادة الاستخدام.

## التشغيل
1. افتح مجلد `DAWWERHA` في Android Studio (Ladybug أو أحدث).
2. انتظر حتى ينتهي Gradle Sync.
3. شغّل التطبيق على جهاز أو محاكي (Android 7.0+).

## حساب الأدمن الافتراضي
- اسم المستخدم: `admin`
- كلمة المرور: `Admin@2026`
- غيّرها في `DEFAULT_ADMIN_PASSWORD` داخل `data/Repository.kt` قبل أي نشر.

## ملاحظات
- كل البيانات محفوظة محليًا عبر Room، ولا يوجد اتصال بالإنترنت.
- معاملات ثاني أكسيد الكربون تقديرية، استبدلها بمعاملات موثقة (EPA WARM / IPCC).
- التعرف على المواد يعتمد على ML Kit العام، وليس نموذجًا متخصصًا في الفرز.
